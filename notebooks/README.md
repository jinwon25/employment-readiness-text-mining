# 분석 노트북 안내

처음 보는 독자는 [`portfolio_summary.ipynb`](./portfolio_summary.ipynb)부터 확인하는 것을 권장합니다. 개인정보가 포함된 원문 없이도 프로젝트의 핵심 집계, 해석 범위와 제도 설계 연결을 볼 수 있도록 실행 결과를 저장했습니다.

| 노트북 | 역할 | 상태 |
|---|---|---|
| `portfolio_summary.ipynb` | 설문·텍스트 핵심 근거와 의사결정 요약 | 공개 집계로 전체 실행 가능 |

| `01_메인_분석.ipynb` | 전처리·EDA·토픽·감정 분석의 전체 작업 과정 | 당시 Colab 절대경로 사용 |
| `02_부정_토픽_모델링.ipynb` | 부정 게시글 LDA·BERTopic 탐색 | 최종 4토픽과 탐색용 3토픽 포함 |
