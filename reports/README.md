# 분석 문서 안내

취업 준비 과정의 감정과 학내 지원 수요를 어떻게 연결할지 다룬 프로젝트입니다. [프로젝트 README](../README.md)는 질문과 주요 발견을, [분석 근거와 적용 범위](ANALYSIS_EVIDENCE.md)는 발표·노트북의 수치와 해석 조건을 설명합니다.

## 읽는 순서

1. [분석 근거와 적용 범위](ANALYSIS_EVIDENCE.md): 설문과 게시글의 표본, 감정 분류 검증, 제안의 근거.
2. [노트북 안내](../notebooks/README.md): 감정 분류 → 부정 글의 토픽 → 지원 수요 유형 순서.
3. [데이터 안내](../data/README.md): 공개 가능한 집계와 공개하지 않는 원문·개인별 응답.

## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| KcELECTRA | 한국어 텍스트 모델입니다. 여기서는 게시글 감정 분류에 사용했습니다. |
| 수동 라벨 | 사람이 감정 범주를 붙인 정답 표본입니다. 전체 수집 게시글 수와 다릅니다. |
| 검증 loss | 정답과 모델 예측의 차이를 학습 목적에 맞춰 요약한 값입니다. 정확도나 서비스 성과와 다릅니다. |
| LDA 토픽 모델 | 함께 나타나는 단어로 글의 주제 분포를 추정하는 방법입니다. 이 프로젝트의 LDA는 토픽 모델을 뜻합니다. |
| K-means | 비슷한 관측을 묶는 방법입니다. 지원 수요 유형의 탐색이며 학생 개인에 대한 확정 진단이 아닙니다. |
| 편의 표본 | 접근 가능한 응답자를 모은 표본입니다. 전체 학생의 대표성을 자동으로 보장하지 않습니다. |
| p-value | 특정 귀무가설 아래 관측 결과의 극단성을 나타내는 값입니다. 효과 크기나 원인의 확정 확률이 아닙니다. |

## 해석 기준

월별 부정 글의 수와 비율을 구분합니다. 감정 분류 모델의 검증 결과와 제도 도입의 효과도 별개입니다. 지원 제도는 제안 단계이며 실제 도입 후 성과로 쓰지 않습니다.
